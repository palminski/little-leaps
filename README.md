# RABIT

### Retro 2D Platformer

RABIT is an arcade style platforming game with retro graphics and a mysterious atmosphere. Its central mechanic is the ability to toggle certain objects on and off at the click of a button. This along with several other movement abilities allows for some devious and exciting platforming sections

It is currently available on steam! If you are interested in playing I would love to hear your feedback! Please feel free to check it out on [Steam](https://store.steampowered.com/app/3536600/RABIT/) or view the launch trailer on [YouTube](https://youtu.be/d2Bm9RNIxXY?si=SQN8uWVH0hqZrF12)!
